# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Requires maintainer evaluation |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use these label strings whenever a skill references a triage role.
Read blocking dependencies separately from readiness labels.
